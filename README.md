# 工艺矿物学磨矿分析系统

面向矿物加工与工艺矿物学教学、科研和现场分析的磨矿计算工具，支持：

- 矿物组成与工艺参数管理
- Bond 能耗、破碎比与磨矿动力学分析
- 解离度预测、筛析数据 RR 拟合
- 回代校准、闭路磨矿质量平衡与过程性评价
- Markdown 分析报告下载

## 在线部署

本仓库用于 Streamlit Community Cloud 免费部署。

- 主文件：`app.py`
- Python 依赖：`requirements.txt`
- 运行数据：`data/minerals.csv`

Streamlit Community Cloud 会生成公开网址，可直接在手机浏览器使用。
